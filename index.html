How the AI writes for the stage

  1. It returns a single JSON object with a cast and an ordered list of actions.
  2. Every action is one of ENTER, EXIT, MOVE, DIALOGUE, LIGHTING, SOUND, BACKDROP, EFFECT, GESTURE, BOW, CAPTION, WAIT or CURTAIN.
  3. The stage engine handles blocking, typewriter bubbles, lights and Web Audio cues.

Quick reference

position
"left", "center", "right", or a number 0–1
lighting
hex colour + intensity 0–1
sound cues
thunder_clap, rain, magic_chime, door_creak, heartbeat, clock_tick, sword_clash, crowd_gasp, applause, wind, bell, waltz, wolf_howl, organ
effects
sparks, lightning, fog, petals, confetti, embers, snow, cards, fireflies, bats
backdrops
gothic_lab, tea_garden, ramparts, fairy_wood, ballroom, dracula_castle, grand_hall
ambient
gothic, wonderland, tragedy, enchanted, ballroom, horror, none

Unknown fields are ignored; unknown actors are cast automatically. Keep dialogue under ~240 characters per line for the best bubble layout.
